# GrowthLabs — grant program letter

**To:** AegisDAO governance
**From:** GrowthLabs
**Date:** 8 October 2026

## Scope

GrowthLabs proposes a six-month ecosystem program covering developer onboarding, four regional meetups, and a matching pool for small grants. The program is operated by the GrowthLabs multisig and reported quarterly.

## Disbursement

GrowthLabs requests a single disbursement of 200,000 USDC to the GrowthLabs multisig. This is a single disbursement, not a recurring grant. No further payment is requested in this proposal.

## Reporting

Quarterly reports will cover attendance, matched grants, and remaining program funds. Reports are published on the GrowthLabs forum account.

## Infrastructure

GrowthLabs will use the DAO's existing treasury infrastructure. "Programmatic disbursement" refers to off-chain reporting automation; it does not request any change to on-chain contracts.
